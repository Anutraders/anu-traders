# Anu Traders Agriculture Store

A React + Vite frontend and Express + SQLite backend for Anu Traders.

## Features
- Agriculture cereal product catalog
- Shopping cart and multi-product checkout
- Customer order tracking at `/track-order`
- Admin order dashboard at `/admin`
- Admin login for order management
- Contact Sales section
- Mobile contact: +91 90921 81767

## Run locally
1. Install Node.js 18+.
2. Start the server from `server`: `npm install && npm start`.
3. Start the client from `client`: `npm install && npm run dev`.
4. Open the Vite URL shown by the client.

## Admin credentials
Default development credentials are in `server/.env.example`. Set `ADMIN_ID` and `ADMIN_PASSWORD` in your server environment for production. Never commit real `.env` files or database files.
